Privacy Policy

Bouquet Turf Uploader. Last updated: November 6, 2026. Back to the tool page

YouTube API Services

Bouquet Turf Uploader uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. Google's handling of your information is described in the Google Privacy Policy.

The tool is used only by the operator of the Bouquet Turf channel, on their own Mac, for that one channel.

Information accessed and collected

  • Google authorization: the tool requests only the youtube.upload permission, which lets it add videos and set their thumbnails on the authorized channel.
  • Content sent to YouTube: the operator's own video file, title, description, tags, thumbnail and visibility setting.
  • Data returned by the API: the ID, URL and visibility of each uploaded video.

The tool does not read viewer data, comments, subscribers, or other channels.

How information is used, stored and shared

  • Information is used only to upload the operator's videos and to let the operator find them afterward.
  • The authorization token and the temporary data used to resume an interrupted upload are stored only on the operator's Mac, in files only that account can read.
  • Uploaded video IDs, URLs and visibility are stored in the operator's private project records, on the Mac and in a private GitHub repository. GitHub stores them as a service provider.
  • Information is sent to Google to perform the upload. It is not sold, not used for advertising, and not shared with anyone else.

Cookies and third-party content

The command-line tool does not use cookies. It shows no ads and serves no third-party content. This website sets no cookies of its own. It is hosted on GitHub Pages, which may log visits as described in GitHub's privacy statement.

Revoking access

You can revoke the tool's access at any time on the Google security settings page. The operator can also run upload_youtube.py revoke, which revokes the token immediately.

Retention and deletion

  • Video IDs, URLs and visibility returned by the API are deleted from the records within 30 days of upload.
  • When access is revoked through the tool, the token and temporary upload data are deleted immediately, and any remaining API data is deleted within 7 days.
  • When access is revoked on the Google security settings page, related API data is deleted within 30 days.
  • A deletion request sent to the contact below is completed within 7 days.

Contact and changes

For privacy questions or complaints, contact the operator by direct message on Instagram: @bouquet_turf.

If this policy changes, the date above is updated. If the tool's use of data expands beyond what was accepted, authorization is requested again.
