Bouquet Turf Uploader

What it does

Bouquet Turf is a Japanese YouTube channel about horse-racing predictions and their tracked results. This command-line tool runs on the operator's own Mac and sends the channel's finished videos, titles, descriptions, tags and thumbnails to that one channel through YouTube API Services.

  • Visibility can be set to private, unlisted or public. The default is private.
  • The operator reviews each video and publishes or schedules it in YouTube Studio.
  • The tool may run from a scheduled job the operator set up on their own Mac. Those uploads are always private.
  • It has no other users and is not offered to anyone else.

What it does not do

  • It does not read viewer data, comments, or other channels.
  • It does not post comments, likes or subscriptions.
  • It does not show ads and earns no revenue.

Works with YouTube

Uploads are made through YouTube API Services.
