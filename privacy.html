bouquet-turf(ブーケターフ 分析ツール) / 2026年11月1日

bouquet-turf は、競馬予想チャンネル「ブーケターフ」の運営者が自分のYouTubeチャンネルの数字を集計するための個人用のツールです。運営者以外の人は使いません。

読み取るデータ

  • 運営者本人のYouTubeチャンネルの分析データ(再生数・視聴時間・登録者数の増減など)だけを読み取ります。
  • 使う権限は YouTube Analytics API の読み取り専用の権限(yt-analytics.readonly)だけです。動画のアップロード・変更・削除はしません。

データの使い方と保存

  • 読み取ったデータは、運営者のパソコンの中でチャンネルの振り返りに使うだけです。
  • 第三者に渡したり、売ったり、広告に使ったりしません。
  • 認証情報(アクセストークン)は運営者のパソコンの中だけに保存し、公開しません。

アクセス権の取り消し

このツールへのアクセス権は、Googleアカウントの「サードパーティのアプリとサービス」からいつでも取り消せます。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に従います。
